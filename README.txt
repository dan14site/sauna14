САЙТ: «Обшивка бань и саун евровагонкой»

ЧТО ВНУТРИ
- index.html — содержимое страницы.
- style.css — оформление и адаптация под телефоны.
- images/sauna-01.jpg ... images/sauna-06.jpg — 6 исходных фотографий работ. Файлы фотографий добавлены без ретуши и цветокоррекции.

КАК БЕСПЛАТНО ОПУБЛИКОВАТЬ САЙТ НА GITHUB PAGES

1. Откройте https://github.com/ и войдите в аккаунт. Если аккаунта нет, зарегистрируйтесь.
2. Нажмите кнопку «+» в правом верхнем углу и выберите «New repository».
3. В поле Repository name введите, например, banya-evrovagonka.
4. Выберите «Public», затем нажмите «Create repository».
5. На странице нового репозитория нажмите «Add file» → «Upload files».
6. Откройте папку проекта banya-eurovagonka-page на компьютере. Перетащите в окно GitHub ВСЁ СОДЕРЖИМОЕ этой папки: файл index.html, файл style.css и папку images. Не загружайте только саму внешнюю папку проекта — файлы index.html и style.css должны оказаться прямо в корне репозитория, а фотографии — внутри папки images.
7. Внизу страницы загрузки найдите раздел «Commit changes». Можно оставить предложенный текст и нажать зелёную кнопку «Commit changes».
8. В репозитории откройте вкладку «Settings».
9. В левом меню найдите «Pages».
10. В блоке «Build and deployment» в поле «Source» выберите «Deploy from a branch».
11. В поле «Branch» выберите «main», а рядом папку «/(root)». Нажмите «Save».
12. Подождите несколько минут и обновите страницу Settings → Pages. Там появится ссылка опубликованного сайта вида https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/.
13. Откройте ссылку и проверьте, что сайт и все 6 фотографий загружаются. Если страница не появилась сразу, подождите ещё несколько минут.

ВАЖНО ПРО ФОТОГРАФИИ
Фотографии в папке images должны оставаться с теми же именами: sauna-01.jpg, sauna-02.jpg, sauna-03.jpg, sauna-04.jpg, sauna-05.jpg, sauna-06.jpg. Не переименовывайте их, иначе галерея не найдёт файлы.

КАК ПОЗЖЕ ОБНОВИТЬ САЙТ
Откройте нужный файл в репозитории, нажмите значок карандаша для редактирования или снова используйте «Add file» → «Upload files». После сохранения изменений GitHub Pages обновит сайт автоматически через некоторое время.

QR-КОД
Сначала опубликуйте сайт и убедитесь, что ссылка работает. Затем QR-код нужно создать именно из окончательной ссылки GitHub Pages. Если в будущем изменится адрес репозитория, может понадобиться новый QR-код.
